# New Member Onboarding

## Discord channels

| Channel | Purpose |
| --- | --- |
| `#start-here` | Rules, role picker, and the quickstart checklist. |
| `#help-desk` | Public support questions answered from docs and code. |
| `#bug-reports` | User-reported bugs before they become GitHub issues. |
| `#announcements` | Weekly release recaps and maintainer notes. |

## First contribution checklist

1. Read `docs/faq.md`.
2. Run `npm test`.
3. Pick an issue labeled `good first issue`.
4. Open a PR that includes a short before/after note.

## Maintainer response targets

- Support questions: first bot answer within 60 seconds.
- Bug reports: label and route within 15 minutes.
- Release recap: every Friday by 3 PM Pacific.
